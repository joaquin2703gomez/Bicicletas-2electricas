
# ⚡ EcoBike - Bicicletas eléctricas

Proyecto web educativo dedicado al mundo de las bicicletas
eléctricas y la movilidad sostenible.

## 🌱 Descripción

EcoBike es una página web informativa que explica cómo
funcionan las bicicletas eléctricas, qué tipos existen y
cuáles son sus ventajas, limitaciones y necesidades de
mantenimiento.

## ✨ Características

- Diseño adaptable a computadoras, tabletas y móviles.
- Navegación interactiva.
- Catálogo informativo de tipos de bicicletas.
- Filtros por categoría.
- Calculadora de autonomía estimada.
- Consejos de mantenimiento.
- Interfaz desarrollada con HTML, CSS y JavaScript.

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- Git y GitHub
- GitHub Pages para la publicación

## 🚀 Cómo ejecutar el proyecto

1. Cloná el repositorio o descargá sus archivos.
2. Abrí `index.html` en tu navegador.
3. Para editar el proyecto, podés utilizar Visual Studio Code.

No es necesario instalar dependencias ni ejecutar un servidor
para probar esta versión básica.

## 🌍 Publicación

El proyecto se puede publicar gratuitamente con GitHub Pages.

## 📌 Información

La calculadora de autonomía proporciona estimaciones orientativas.
Los resultados reales dependen de las características de la
bicicleta y de las condiciones de uso.

Las imágenes externas pertenecen a sus respectivos autores y
proveedores. Revisá sus licencias y condiciones de uso antes
